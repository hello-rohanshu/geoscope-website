## 1. What is this?
This is a digital version of Buckminster Fuller's Geoscope concept. Its goal is to make Spaceship Earth more comprehendible, allowing its crew to know "what is up" with the ship.

## 2. Why does this matter?
In Bucky's book "Critical Path" he details humanity's core problems, two of which are solved by World Game (solving specialization as bias), and Synergetics (making visible nature's (god's) seeming invisibility) respectively. The third problem is that of humanity's nervous system's inability to comprehend huge time scale patterns which universe operates in, making humans incapable of knowing where we are headed as a species. Geoscope is his solution to this problem.

## Notes for AI Collaborators

This project is built with AI assistance. If you are an AI reading this, here is what you need to know:

### Context
- This is a digital Geoscope inspired by Buckminster Fuller's "Critical Path"
- The goal is not a tech demo. The goal is a working control panel for Spaceship Earth
- The project is early. Most sections are proof-of-concept, laggy, and use illustrative (fake) data
- The Dymaxion population map is the only section with real data right now

### The stance
- Treat the project as if it is already live in front of a huge audience
- Treat the work as if we are a professional team
- Act as if the next person to read this has no memory of prior conversations
- This README is the shared memory. It must stay honest and current

### Working rules
- Be honest about what is broken. Label fake data as illustrative
- Do not mix polished and unpolished UI. Pick one fidelity and hold it
- Small, real steps beat grand plans. Fix one thing properly
- Update the README changelog when things change
- The roadmap is: pick ONE section, make it work on mobile and PC, set the standard, repeat

### Principles (abbreviated)
- The project is already live. Act accordingly
- Honest about its state. Always
- Working means working. Broken means gone or labeled
- Do more with less

## 5. General Working Principles
- **Iterative Standardization**: Focus on making one component work fully on both mobile and PC to establish a standard before moving on to others.
- **Macro-Scale Focus**: Ensure all visualizations and UI elements serve the core goal of making large-scale temporal and spatial patterns comprehensible.
- **Continuous Iteration**: Apply consistent iterative rehauls to update all components once new standards are established.
